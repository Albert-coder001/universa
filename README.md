# UNIVERSA

Адаптивный демонстрационный прототип цифрового кампуса на Next.js. Данные и функции работают локально в браузере; серверная авторизация и интеграции с университетскими системами не подключены.

## Запуск

Требуется Node.js 18.17 или новее.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Демонстрационные университеты и аккаунты

На экране входа нажмите на нужный аккаунт и затем «Войти в кампус»:

- СТУ: `student@stu.demo` / `demo123` — Александра Смирнова, ИТ-21.
- ПГУ: `student@pgu.demo` / `demo123` — Мария Волкова, ЭК-22.

Данные обучения и анкеты напарника различаются; анкеты сохраняются отдельно в текущем браузере. Вход является демонстрационным: данные и пароли находятся в коде приложения, серверной защиты и реальной изоляции пользователей нет.

## Что можно показать

- Главная, расписание, новости, напоминания и уведомления.
- Успеваемость по четырём предметам с историей оценок и анимированными индикаторами.
- AI-декан с mock-ответами и ссылкой на источник. Кнопки создания черновика справки нет.
- Запрос документа в PDF, включая вариант «Другое».
- Инициативы и голосование в «Голосе студента».
- Поиск напарников, профиль и адаптивная мобильная навигация.

Это конкурсный UI-прототип: данные демонстрационные, PDF-загрузка, отправка заявок и серверный AI не подключены.
